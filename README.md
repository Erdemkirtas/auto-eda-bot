Auto-EDA Bot is an **Autonomous Data Scientist Agent** powered by LangChain and Azure OpenAI. It allows users to upload datasets (CSV/Excel) or scrape data from URLs, and then interact with the data through a chat interface. The AI agent automatically writes Python code, performs Exploratory Data Analysis (EDA), generates insights, and creates interactive charts based on user queries.

## ✨ Features

*   **Autonomous Analysis:** Just ask questions like *"Analyze this dataset"* or *"Show me the correlation between X and Y"*, and the agent will write and execute the necessary Python code in real-time.
*   **Multi-Tenant Architecture:** Secure user authentication (JWT) and complete data isolation. Each user's uploaded files, chat history, and generated charts are completely isolated.
*   **Interactive Chat UI:** A modern, glassmorphism-inspired dark/light themed React frontend.
*   **Streaming Responses:** Real-time token streaming for AI responses, so you can see the agent's thought process and generated code live.
*   **Voice Input:** Built-in speech-to-text support for asking questions hands-free.
*   **Rich Media Rendering:** Automatically renders generated PNG plots and interactive HTML charts directly in the chat window.
*   **PDF Reports:** Export your entire analysis session into a downloadable PDF report.

## 🚀 Getting Started

### Prerequisites
*   Python 3.12+
*   Node.js 20+
*   Azure OpenAI API Key

### 1. Clone the Repository
```bash
git clone https://github.com/Erdemkirtas/auto-eda-bot.git
cd auto-eda-bot
```

### 2. Backend Setup
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r ../requirements.txt
```

Create a `.env` file in the `auto-eda-bot` root directory:
```env
AZURE_OPENAI_API_KEY="your-api-key"
AZURE_OPENAI_ENDPOINT="https://your-endpoint.openai.azure.com/"
AZURE_OPENAI_DEPLOYMENT="your-deployment-name"
JWT_SECRET_KEY="your-super-secret-key"
```

Start the FastAPI server:
```bash
uvicorn main:app --reload --port 8000
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

The application will be available at `http://localhost:5173`.

## 🛠️ Tech Stack
*   **Backend:** FastAPI, SQLAlchemy (SQLite), LangChain, LangGraph, Python REPL
*   **Frontend:** React, Vite, CSS (Glassmorphism UI)
*   **Authentication:** JWT, passlib, bcrypt

## 🔒 Security
Code generated by the AI is executed in the local Python environment. In a production setting, the execution sandbox should be containerized (e.g., using Docker) to prevent arbitrary code execution on the host machine. (Sandbox isolation feature is upcoming!)
